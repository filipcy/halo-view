# Roadmap

## V1 — Hardware MVP

Goal: install a finished-looking, serviceable HALO View using the existing Home Assistant dashboard.

- Freeze measurements and cable choice.
- Produce Dock Rev A and Faceplate Rev A CAD.
- Print fit-test sections before full-size production.
- Release printable files and manufacturing notes.
- Install with Dual Lock on tile.
- Complete seven-day field test.

## V1.1 — Refinement

- Correct fit and tolerance findings.
- Improve surface finish and assembly ergonomics.
- Finalise installation template and documentation.

## V2 candidates

- HALO-native interface and design system.
- Contextual home-management insights.
- Reserved ambient-status light module.
- HALO Paper e-paper companion.

V2 candidates do not alter the V1 release gate.
