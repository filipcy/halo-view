## Existing visual reference

Photos were captured with a Polish 2 grosze coin as scale reference. These are useful for geometry review but are not sufficient for final fit tolerances.

## Initial tolerance targets

These are starting assumptions for prototype design, not released values:

- general tablet envelope clearance: 0.25–0.50 mm per side;
- non-cosmetic part-to-part sliding clearance: 0.30–0.50 mm;
- display overlap: minimal and outside the active display area;
- soft contact layer allowance: 0.3–1.0 mm where required;
- USB connector chamber: validate against the selected 90-degree cable before release.
