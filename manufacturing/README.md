# Manufacturing

This area contains controlled preparation records for outsourced manufacture:

- print-service requirements;
- material and finish specification;
- orientation and support guidance;
- inspection checklist;
- installation template;
- released production notes.

The [`HALO_Dock_Rev_A_External_Print_Candidate/`](HALO_Dock_Rev_A_External_Print_Candidate/) package provides the Sprint 3 vendor specification, RFQ checklist, receiving-inspection checklist, and generated-part manifest. It mandates matte black PETG, 0.20 mm layers, no supports, 100% scale, and no supplier mesh repair. Coupon approval precedes any full-size print candidate authorization.

No manufacturing release is valid until the matching CAD revision, native CAD/export validation, checksums, and prototype findings are documented.
