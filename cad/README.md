# CAD

HALO View mechanical source, review records, and controlled manufacturing exports live here.

## Structure

- `source/` — editable source models and generators
- `reviews/` — iteration review notes and review graphics
- `exports/` — neutral STEP exports
- `stl/` — released print meshes
- `prototypes/` — fit-test and Rev A sections
- `references/` — validated reference geometry

## HALO Dock Rev A

The Sprint 3 external print candidate is generated by [`source/HALO_Dock_Rev_A.py`](source/HALO_Dock_Rev_A.py). It retains Iteration 2 geometry and adds three clearance coupons, a Faceplate corner/lip coupon, a guide/shelf insertion coupon, and a wall-stack/shadow-gap coupon. The full-size Faceplate and DockBody remain PRINT CANDIDATE ONLY.

See [`reviews/HALO_Dock_Rev_A_Iteration_2.md`](reviews/HALO_Dock_Rev_A_Iteration_2.md) and its [review schematic](reviews/HALO_Dock_Rev_A_Iteration_2.svg) for scope, exclusions, projection math, and release gates. The [Iteration 1 review](reviews/HALO_Dock_Rev_A_Iteration_1.md) remains the accepted baseline record.

Vendor instructions, RFQ controls, receiving inspection, and the file manifest are in [`../manufacturing/HALO_Dock_Rev_A_External_Print_Candidate/`](../manufacturing/HALO_Dock_Rev_A_External_Print_Candidate/). Generated STEP and STL files are not checked in until a native Fusion run has passed the documented gates.

Released files must use controlled part names and revision identifiers. Generator output is a working artifact until its review gates are closed and it is explicitly copied into a release directory.
