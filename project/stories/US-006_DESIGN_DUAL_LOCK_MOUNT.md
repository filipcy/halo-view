# US-006 — Design the Dual Lock wall mount

**Epic:** EPIC-001  
**Status:** TODO

## User story

As a homeowner, I want HALO View mounted securely to tile without drilling, so that the installation is reversible and visually clean.

## Description

Design the wall-side Dock interface for 3M Dual Lock SJ3550 or a validated equivalent. The mounting fields must hold the complete assembly during normal use while still allowing deliberate service removal.

No screws, wall plugs or permanent mechanical fixings are permitted in V1.

## Acceptance criteria

- [ ] Assembly mounts to clean tile using only the approved reclosable fastener.
- [ ] Mounting fields are hidden in normal use.
- [ ] Panel remains level and does not rotate during touch interaction.
- [ ] Dock can be deliberately removed without tools and without pulling on the tablet.
- [ ] Faceplate/tablet service does not require removing the wall-side adhesive interface.
- [ ] Mounting geometry allows accurate levelling before final pressure is applied.
- [ ] The design documents tile preparation, adhesive cure time and removal method.
- [ ] Mounting reserve is appropriate for the measured assembly mass and touch loads.

## Tests

1. Mount a representative mass to a test surface using the intended Dual Lock area and preparation method.
2. Leave mounted for seven days and inspect for creep, rotation or partial release.
3. Apply repeated normal touch loads at screen corners.
4. Remove and reconnect the mechanical Dual Lock interface ten times.
5. Verify that service access does not disturb adhesive bonded to the tile.
