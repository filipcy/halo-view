# HALO View

HALO View is a wall-mounted home interface designed around architecture, not around a tablet.

It transforms a Samsung Galaxy Tab A11 (SM-X130) into a permanent, calm and serviceable element of the interior. Home Assistant is the backend; HALO is the product experience.

## Current status

- Product: HALO View
- Hardware target: Samsung Galaxy Tab A11 SM-X130
- Orientation: portrait
- Hardware stage: Rev A / engineering definition
- Software stage: existing Home Assistant dashboard as MVP

## V1 objective

Mount the tablet without drilling, hide the cable, preserve easy service access and make the device look as if it belonged in the room from the beginning.

## Core principle

> HALO should never look like a tablet mounted on a wall.
